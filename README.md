# Student Registration Prototype — Introductory Web Development

> An introductory-course project created while learning the basics of HTML, CSS, and JavaScript.

## About

This repository is an early learning exercise, **not** part of my more recent data analytics coursework. It explores how to structure a simple web page and implement basic student-record operations with JavaScript.

## Technologies

- HTML: a student registration form and page structure
- CSS: basic presentation and layout
- JavaScript: array-based student records, prompts, and simple CRUD-style functions

## Project files

| File | Purpose |
| --- | --- |
| `index.html` | Page markup and registration form |
| `main.css` | Visual styling |
| `app.js` | Console/dialog-based sample registration logic |

## Current limitations

The HTML form is a separate prototype and does not currently submit records to the JavaScript data array: the script reference in `index.html` is commented out. The JavaScript also contains introductory control-flow issues, so the project should not be presented as a finished registration application.

**Data note:** The original JavaScript contains sample student contact information. Those entries have not yet been vetted for public reuse. Do not treat them as real user records or reuse this sample dataset in other projects.

## Learning outcomes

This exercise documents an early introduction to web technologies and programming logic. It is intentionally distinguished from later projects in Python, SQL, and analytics.
